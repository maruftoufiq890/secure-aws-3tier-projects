# Secure AWS 3-Tier Architecture

A production-style secure, highly available and scalable
3-tier web application architecture on AWS.

# Project Goals

- Build a secure AWS network
- Deploy application servers
- Implement load balancing
- Implement high availability
- Implement scalability
- Configure a managed database
- Implement monitoring

## AWS Services

- Amazon VPC
- Amazon EC2
- Application Load Balancer
- Auto Scaling
- Amazon RDS
- Internet Gateway
- NAT Gateway
- Security Groups
- IAM
- CloudWatch
